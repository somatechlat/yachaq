# Yachaq Platform Documentation

Welcome to the central documentation hub for the Yachaq Platform. This section contains architectural overviews, setup guides, and links to the auto-generated API and SDK documentation.

## Documentation Sections

*   **[Architecture Overview](./ARCHITECTURE.md):** A high-level description of the Yachaq platform's components, design principles, and overall architecture. This is the best place to start to understand how the system works.

*   **API & SDK Documentation:**
    *   **GraphQL API:** The schema is documented directly in the `.graphqls` file. It defines all available queries, mutations, and subscriptions. You can find it at `yachaq-platform/yachaq-api/src/main/resources/graphql/schema.graphqls`.
    *   **Java API (Javadoc):** *This documentation is generated by the build process and published to GitHub Pages. It is not checked into the repository.*
    *   **TypeScript SDK (TypeDoc):** *This documentation is generated by the build process and published to GitHub Pages. It is not checked into the repository.*

## How Documentation is Generated

This project uses a GitHub Actions workflow to automatically build and publish the Javadoc and TypeDoc sites to GitHub Pages.

-   The workflow is defined in `.github/workflows/publish-docs.yml`.
-   On every push to the `main` branch, the action runs, generates the documentation, and pushes it to the `gh-pages` branch.
-   The published site can be accessed at the GitHub Pages URL configured for this repository.
